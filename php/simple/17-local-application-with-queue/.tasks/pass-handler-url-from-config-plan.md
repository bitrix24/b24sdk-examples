# План: вынести URL обработчика активити в конфиг для `TestCommand`

## Summary

Убрать хардкод `https://.../crm-activity-handler.php` из `TestCommand` и получать handler URL из конфигурации приложения. В качестве источника конфигурации использовать общий публичный `Base URL`, из которого в коде собирается путь до `/crm-activity-handler.php`.

## Implementation Changes

- Добавить в конфиг новую env-переменную для публичного базового URL приложения, например `APP_PUBLIC_BASE_URL` или аналогичное имя в текущем стиле проекта.
- Зарегистрировать значение этой переменной в DI так, чтобы `App\Infrastructure\Console\TestCommand` получал его через конструктор, а не читал `$_ENV` напрямую.
- Обновить `TestCommand`:
  - принять base URL через DI;
  - централизованно собрать handler URL для `crm-activity-handler.php`;
  - заменить текущий хардкод на значение из конфига;
  - при необходимости нормализовать хвостовой `/`, чтобы не получить двойной слеш в итоговом URL.
- Обновить `.env`:
  - добавить новый ключ с пустым или примерным значением и коротким комментарием, зачем он нужен;
  - не класть рабочее значение в репозиторий, фактическое значение ожидается в `.env.local`.
- Обновить `README.md`:
  - описать новый обязательный параметр;
  - указать, что для CLI-установки активити должен быть задан публичный base URL, доступный Bitrix24.
- Если в проекте есть связанный чеклист по этой задаче вне текущего дерева, после реализации отметить пункт как выполненный.

## Public Interfaces / Config

- Новый внешний конфигурационный параметр: публичный base URL приложения.
- Конструктор `TestCommand` изменится: кроме текущих зависимостей будет принимать строку base URL из контейнера.

## Test Plan

- Проверить статически, что контейнер собирает `TestCommand` с новым аргументом.
- Проверить через `make`:
  - `make lint-cs-fixer`
  - `make lint-phpstan`
  - при наличии необходимости `make lint-rector`
- Ручной сценарий:
  - задать публичный URL в `.env.local`;
  - запустить `make php-cli-app`;
  - выбрать `Install activity`;
  - убедиться, что в Bitrix24 у активити регистрируется URL вида `<base-url>/crm-activity-handler.php`, а не прежний хардкод.

## Assumptions

- Выбран вариант с общим публичным `Base URL`, а не с отдельной переменной под полный handler URL.
- Для этой задачи достаточно изменить только CLI-flow в `TestCommand`; вынос аналогичной логики из `InstallController` в общий сервис не входит в обязательный минимум.
- Отдельного чеклист-файла в текущем репозитории нет, поэтому его обновление потребуется только если он ведётся вне этого дерева.
